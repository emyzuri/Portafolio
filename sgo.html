Sistema de Notas (SGO Oxford Gardens)

Portal educativo y sistema de notas desarrollado para la institución UE Oxford Gardens.

📌 Descripción del Sistema

Plataforma web creada para administrar los procesos educativos de la institución: ingreso de notas, expediente del estudiante, asistencias y matrículas en línea.

⚡ Módulos & Logros Clave

  • Portal de notas y calificaciones.
  • Autenticación y roles (Admin, Docente, Alumno).
  • Base de datos MySQL optimizada para +3,800 estudiantes.
TECNOLOGÍAS UTILIZADAS:
PHP MySQL JavaScript ES6+ HTML5 / CSS3 Apache
